# Post style files / файлы стиля поста

Optional. Put your own post prompt and an example post here (they are git-ignored):

- `prompts/post_prompt.md` — instructions for DeepSeek on how to write the post
- `prompts/post_example.md` — an example of a good post

Paths are configured in `konveyer.toml` → `[post] style_files`. Without them a generic style is used.

Необязательно. Положите сюда свой промпт и пример поста (в git не попадают). Пути — `[post] style_files`.
